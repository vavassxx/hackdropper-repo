# Grindlands UI fonts

Put `GoogleSans-Regular.ttf` here. The server automatically streams `.ttf`/`.otf` files in this directory to clients. Custom UI widgets can select one with `font = "GoogleSans-Regular.ttf"`.

Google Sans is published by Google under the SIL Open Font License. The official source/release is the Google Fonts `googlefonts/googlesans` repository.
