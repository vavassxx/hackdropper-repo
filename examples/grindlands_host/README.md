# Grindlands

Небольшая action-RPG на LuaJ scripting API openRPGator.

## Архитектура

Игровая логика разделена по ответственности:

- `host/game.lua` — единственный мировой coordinator: состояние игроков, definitions, HUD,
  команды, бой, AI мобов, респаун и экономика.
- `host/mob.lua` — только регистрация состояния конкретного моба и его `on_interact`.
- `host/resource.lua` — только регистрация ресурса и сбор.
- `host/coin.lua` — только регистрация монеты и подбор.
- `host/npc_merchant.lua` — торговец.
- `host/npc_healer.lua` — целитель.
- `host/grindlands-ui.lua` — прозрачный client-side bridge для `Script` sandbox.

Мировое состояние хранится в `_G.GRINDLANDS`, потому что LuaRuntime предоставляет единый
LuaJ runtime для скриптов карты. Entity scripts не создают собственные игровые циклы: один
`game.lua` координирует симуляцию, а entity scripts регистрируют только локальные события.

## UI

Используется штатная цепочка openRPGator:

`engine.layout` → `UiLayout(kind=layout)` → `ClientScriptEngine` → `GameView`.

Клиентский Lua не хранит состояние игры и не парсит текст HUD обратно в данные. Он является
прозрачным мостом: передаёт layout renderer'у и отправляет на сервер нажатия кнопок.

## Карта и ресурсы

- `host/grindlands.rmap` — карта 64×64.
- `host/grindlands.pak` — исходный набор ассетов.

Скриптовые привязки сущностей в `.rmap` соответствуют их роли: manager, mob, resource, coin,
merchant или healer.

## Запуск

Из корня openRPGator:

```bash
gradle :dedicated-server:installDist
./dedicated-server/build/install/dedicated-server/bin/dedicated-server \
  --data-dir grindlands_host --port 27800 --tick-rate 20
```

Или:

```bash
./grindlands_host/start.sh
```

Клиент подключается к `localhost:27800`.

## Управление

- WASD/стрелки — движение.
- J — атака мобов; L — взаимодействие/сбор. На Android кнопка A соответствует атаке, E — взаимодействию.
- Инвентарь и Персонаж — кнопки HUD.
- Внутри инвентаря кнопки предметов отправляют authoritative command на сервер.

## Игровая модель

Игрок начинает в центре карты. Доступны 21 тип оружия и кулаки. Мобы усиливаются по мере удаления от центра.
Ресурсы собираются и продаются торговцу. Смерть отнимает 10% золота и отправляет игрока
на респаун. XP может поднять сразу несколько уровней, если накоплено достаточно опыта.

Прогресс персонажа в этой версии хранится только в памяти сервера; persistence намеренно
не добавлялся в пример, поскольку для него нужен отдельный storage API.


## Требование к openRPGator

Для боевой кнопки используется семантический `engine.on_action`: текущий master до этого изменения
передавал `Input.PRIMARY` от клиентов, но `ServerHost` его не маршрутизировал в scripting API.
Патч движка добавляет `engine.on_action(function(player, action))`; Grindlands использует action=`primary`.
`INTERACT` при этом сохраняет штатный `entity.on_interact`.

HUD дополнительно показывает ближайшую цель и её текущее HP.


## Стартовая экономика

Персонаж начинает с кулаками: они наносят базовый урон, поэтому прогресс не запирается за первым оружием.
Золото можно получать тремя способами:

- подбирать золотые монеты на карте через обычное взаимодействие;
- собирать руду, траву и дерево и продавать их торговцу;
- убивать мобов и получать их награду золотом.

Торговец теперь действительно продаёт оружие. Нож стоит 15 золота, короткий меч — 35, меч — 60 и т.д.
